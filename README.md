# Rock Paper Scissors — CLI Game

A simple terminal-based Rock-Paper-Scissors game in Python where you play against a randomly-choosing computer opponent.

## Description

This is a command-line implementation of the classic Rock, Paper, Scissors game. The player enters a move, the computer picks one at random, and the winner is determined and displayed.

## How to Play

Run the script and enter one of the following when prompted:

| Input | Move |
|-------|------|
| `r`   | Rock |
| `p`   | Paper |
| `s`   | Scissors |
| `x`   | Exit the game |

## Requirements

- Python 3.x

## Usage

```bash
python game1.py
```

## Example

```
Enter your move: r
You chose: Rock
Computer chose: Scissors
you win!
```

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same move = Draw
